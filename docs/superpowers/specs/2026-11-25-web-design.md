# C3 BLE Debugger Web 控制台

用户确认采用本地 Web 控制界面，自己操作整个测试流程。

流程：串口连接与身份验证；配对新设备或选择已有绑定；输入按键数量；逐键命名并手动开始、停止采样、确认或重测、跳过；导出结果。

用户进一步指定浏览器 Web Serial 直接连接 C3。使用静态 HTML/CSS/JS，无需后台服务，仅提供 Web 界面。浏览器须支持 Web Serial，并由用户点击授权串口。

每次采样独立，只有开始后的通知归属当前按键。结果在浏览器本地保留尝试历史、原始报文、状态、设备和通道信息。停止即保存并切换下一键，不设确认通过或跳过。结果显示同次采样去重后的多个 HEX 值。断线或丢包中止当前采样并标记异常，支持重测。仅导出 CSV（按键、键值两列）；未完成项明确标识。浏览器本地存储保存结果。刷新关闭串口，未结束采样标记异常，结果可恢复。

蓝牙操作显示进度和错误，不自动重试配对或写入。发现的通知通道可选择；自动优先 HID 通道，订阅失败可见。首版只支持已有固件的 Just Works 配对，不保证 PIN 设备。

不重新打包，不更改已验证的底层蓝牙行为。Web 版本以 VERSION 为准，板上固件仍为 0002，分别显示。
